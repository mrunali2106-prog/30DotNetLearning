 interview questions
 1) What is a switch statement?
 -> switch makes menu driven programs easier to read when checked difference.
 
 2)When should you use switch instead of if-else?
 ->Use switch when you need to compare one variable against multiple fixed values.
 
 3)What is the purpose of break?
 ->break is used to exit the current case after its code has executed.
 
 4)What is the purpose of default?
 -> The default block executes when no case matches the switch expression.
 
 5) What happens if you omit break?
 -> In C#, omitting break (without another jump statement like return or throw) causes a compile-time error because control cannot fall through to the next non-empty case.
 
 6) Can a switch work with strings in C#?
 -> Yes, C# allows switch statements to work with string values.
 
 7)When is if-else a better choice than switch?
 -> Use If else when checking ranges,comparisons or complex logical conditions.
