Important:
if
Executes code when condition is true.

else
Executes when condition is false.

else if
Checks another condition if the previous one is false.

Interview Questions:
1) What is if statement?
-> A decision making statement.
2) Difference between if and else if?
-> if checks the first condition.
else if checks the next condition if the previous one is false.
3)What is &&?
-> Logic AND Operator.
4) What is ||?
-> Logic OR Operator.
5) What is the purpose of the else block?
-> The else block executes when the if condition is false.
6) Can we use an if statement without an else?
-> Yes, an if statement can be used without an else block.
7) What happens if all conditions are false?
-> If all conditions are false, the else block runs if it is present. If there is no else block, the program skips the conditional statements and continues executing the remaining code.
